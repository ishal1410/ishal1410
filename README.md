I'm a backend and machine learning engineer. I build production services and the ML systems behind them, then measure whether they hold up. Most of what's here started as a question I couldn't answer by reading, so I built the thing and checked the numbers. In 2026 my rental-scam checker [depositcheck](https://github.com/ishal1410/depositcheck) won the SerpApi "Best AI Use Case" award at the DevNetwork API+Cloud+AI Hackathon, and I have two pull requests open against [DataHub](https://github.com/datahub-project/datahub/pulls/ishal1410).

## Things I've built 🔧

- [depositcheck](https://github.com/ishal1410/depositcheck) · checks whether a rental listing's photos already belong to a different address before you wire a deposit. Next.js, SerpApi.
- [ninetyninety](https://github.com/ishal1410/ninetyninety) · drafts an IRS Form 990-EZ from a bank export with two independent agents, validated against 3,632 real filings. Python, Strands Agents.
- [realtime-chat-app](https://github.com/ishal1410/realtime-chat-app) · distributed chat backend. GraphQL, WebSockets, Redis Pub/Sub, Kafka, Kubernetes.
- [ml-serving-platform](https://github.com/ishal1410/ml-serving-platform) · EfficientNet-B0 served behind FastAPI, provisioned with Terraform, monitored with Prometheus and Grafana.
